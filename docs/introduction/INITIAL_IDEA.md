# SASI KUTTAN

Sasi Kuttan is supposed to be an ai assistant, that can perform basic tasks like code cleaning, organising, generating documentations etc. The main objective of Sasi Kuttan is to enable smaller models without native tool calling capabilites to perform these tasks.


## HOW IS THIS DIFFERENT FROM POPULAR AGENTS

- Popular agents typically use native tool calling capabilites to perform tasks, while Sasi Kuttan is designed to work with smaller models without native tool calling capabilites.
- Low-end devices can run Sasi Kuttan using smaller models hosted locally to perform these tasks.
- Sasi Kuttan can also be a good companion while you code. 
- I try to make it as light as possible, so that it can run on low-end devices, which may be misleading cause I'm using python.
- Not many people are gonna know about Sasi Kuttan.
- Sasi Kuttan is not perfect but Sasi Kuttan tries really hard.
