# Sasi Kuttan

Sasi Kuttan is supposed to be an ai assistant, that can perform basic tasks like code cleaning, organising, generating documentations etc. The main objective of Sasi Kuttan is to enable smaller models without native tool calling capabilites to perform these tasks. We believe smaller models deserve love too. **#justiceforsmallermodels**

> Know more about Sasi Kuttan [IDEA OF SASI KUTTAN](docs/introduction/INITIAL_IDEA.md)
